SkautGram — сервер подтверждения номера через Telegram-бота

ВАЖНО
- Это серверный прототип подтверждения номера, а не готовый публичный сервис.
- SkautGram остаётся отдельным мессенджером. Telegram здесь используется только как канал доставки кода после явной привязки.
- Бот НЕ может первым написать человеку по номеру. Пользователь должен открыть deep-link бота и нажать кнопку «Поделиться моим номером».
- В этом прототипе код отправляется только после того, как Telegram подтвердит, что пользователь поделился собственным контактом и номер совпал с введённым в приложении.
- Нынешний Android-интерфейс ещё не подключён к этому API; для реального входа потребуется следующий этап интеграции и размещение сервера в интернете.

ЗАПУСК ДЛЯ РАЗРАБОТЧИКА
1. Нужен Node.js 20+ и HTTPS-хостинг с постоянным диском.
2. Создать бота через @BotFather. Сохранить токен в секрете хостинга, не публиковать его.
3. Указать переменные из .env.example: BOT_TOKEN, BOT_USERNAME, CODE_PEPPER (длинная случайная строка), DB_FILE.
4. Запустить: npm start
5. Проверить GET /health.

API
POST /api/auth/start  JSON: {"phone":"+4915112345678"}
Ответ содержит botUrl. Клиент должен открыть эту ссылку.
POST /api/auth/verify JSON: {"challengeId":"...","code":"123456"}

ПРЕДУПРЕЖДЕНИЕ О БЕЗОПАСНОСТИ
Это минимальный прототип: JSON-хранилище подходит только для тестирования с одним экземпляром. Перед реальным запуском нужны база данных, лимиты запросов по IP/номеру, мониторинг, политика конфиденциальности, удаление данных, резервные копии и аудит безопасности. Не используйте его для настоящих пользователей до этих доработок.
