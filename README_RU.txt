SkautGram — Telegram-inspired UI package

Этот архив обновляет визуальную часть Android WebView-проекта SkautGram.
Интерфейс использует привычную для мессенджеров компоновку: список чатов,
поиск, папки, шапку переписки, пузырьки сообщений и поле ввода.

Важно:
- Это самостоятельный проект SkautGram, не официальный Telegram-клиент.
- Не копируются фирменный логотип, название или закрытые элементы Telegram.
- Текущая версия остаётся демонстрационной WebView-оболочкой.
- Переписки, профиль, подарки и балансы в этой версии локальные.
- Для реальных пользователей необходимы сервер, база данных, API,
  авторизация, хранение файлов, push-уведомления и отдельная реализация звонков.
- Звёзды и TON в текущем интерфейсе — демонстрационные внутренние единицы,
  не реальные криптоактивы и не переводимые средства.
- Номера +1/+888, если генерируются приложением, являются только
  внутренними идентификаторами, а не действующими телефонными номерами.

Сборка APK выполняется существующим GitHub Actions workflow проекта.
